AgentTipJar

A tip jar on BNB Chain that only Agent ID (.ai) holders can use — to send and to receive. Your Agent ID is your pass, your identity and your anti-spam shield.

Risk warning: crypto assets are volatile. Tips are irreversible BNB transfers forwarded instantly to the receiver. This demo is not financial advice and promises no returns.

How it works

  1. Hold an Agent ID (name.ai) in your Binance Agentic Wallet.
  2. Connect any EVM wallet holding that address and send a tip to another Agent ID holder.
  3. The contract checks balanceOf on the official Agent ID registry for both sides, forwards the BNB instantly (non-custodial — the contract never holds funds), and records the stats you see above.

Source code is fully open and verified on BscScan. No owner, no admin keys, no pause, no withdrawal function.
